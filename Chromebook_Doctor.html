      Budget par image

      C'est le temps total dont dispose chaque image pour le calcul, le dessin et le GPU. Une image qui dépasse ce budget crée une saccade. Les points rouges du tracé sont les images trop longues.

      Benchmark du processeur et de la mémoire

      Un seul cœur

      Calcul pur sur un cœur. Représente une page ou un jeu qui ne sait pas se répartir. Plus c'est court, mieux c'est.

      --

      Tous les cœurs

      Le même calcul sur chaque cœur en même temps. Montre si la machine tient la charge ou si elle chauffe et ralentit.

      --

      Mémoire

      Débit en écriture et lecture sur 32 Mo. Indicatif seulement, il n'entre pas dans le score.

      --

      Les seuils de notation sont des repères approximatifs pour un Chromebook, pas une norme. Relance les mesures sur secteur et sans autre onglet lourd pour comparer avant et après un nettoyage : la page se souvient de ta dernière mesure.

      Checklist d'entretien

      Une page web ne peut pas nettoyer ton système à ta place. Cette liste te mène aux bons réglages, et les mesures de l'onglet FPS et Benchmark te disent si ça a servi.

      Gagner des FPS en jeu

      Avant de jouer

      • Branche le chargeur. Sur batterie, le processeur peut être bridé pour économiser l'énergie.
      • Ferme le reste. Onglets, applis Android, téléchargements. Ouvre le Gestionnaire de tâches avec Recherche + Échap pour voir les plus gourmands.
      • Pose-le sur une surface dure. Un processeur qui chauffe baisse sa fréquence.

      Dans le jeu

      • Baisse la résolution du rendu en premier. Le nombre de pixels pèse directement sur le GPU.
      • Coupe ombres, antialiasing et particules. Ce sont les effets qui coûtent le plus pour le moins de gain visible.
      • Vise 30 FPS stables plutôt que 60 instables : 33,3 ms par image au lieu de 16,7 ms.

      Si ça rame encore

      • Vérifie l'accélération matérielle dans chrome://gpu. Si elle est en rendu logiciel, le GPU n'est pas utilisé.
      • Passe au jeu en streaming (GeForce NOW, Xbox Cloud Gaming dans Chrome). Le calcul se fait à distance, il te faut une bonne connexion.
      • Powerwash en dernier recours, après sauvegarde de tes fichiers.

      Pages de diagnostic de ChromeOS

      Une page web ne peut pas ouvrir les adresses chrome://. Copie l'adresse, ouvre un nouvel onglet et colle-la.

      Raccourcis utiles

      • Recherche + Échap : Gestionnaire de tâches, pour voir quel onglet ou quelle extension consomme.
      • Ctrl + Maj + Retour arrière : effacer les données de navigation.

      Mode jeu

      Prépare le Chromebook pour jouer : plein écran, écran toujours allumé, touches verrouillées et compteur de FPS flottant. Une page web ne peut pas changer les réglages du système, alors ce mode règle ce qu’il peut et te signale le reste.

      Avant de jouer

        Options

        Si l’écran reste noir ou blanc, le site refuse d’être intégré : ouvre-le dans un nouvel onglet.

        Ce que le mode jeu ne peut pas faire : fermer tes autres onglets, changer la fréquence du processeur ou activer le mode performance du système. Branche le chargeur et suis la checklist de l’onglet Jeux.

          Saturation sur les sites web

          Pour saturer les pages web ouvertes dans Chrome, installe l’extension « Écran & Son » fournie dans le ZIP, puis règle son curseur Saturation (0 à 200 %) depuis son icône. Elle applique le filtre aux pages web, y compris aux jeux joués dans le navigateur. Le curseur de cette page agit sur Chromebook Doctor et son lecteur intégré.

          • Pour installer l’extension : ouvre chrome://extensions, active le mode développeur, puis choisis « Charger l’extension non empaquetée » et sélectionne le dossier ecran-et-son extrait du ZIP.
          • Le curseur de l’extension agit sur les sites web dans Chrome, pas sur les menus de ChromeOS ni sur les jeux/applications lancés hors du navigateur.
          • Pour les réglages d’accessibilité de l’écran : Paramètres → Accessibilité → Affichage et agrandissement → Correction des couleurs. ChromeOS ne fournit pas ici un curseur libre de saturation à 200 %.
